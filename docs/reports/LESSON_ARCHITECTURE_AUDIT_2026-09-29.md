# Lesson architecture audit — 2026-09-29

> **Point-in-time record.** The contract that came out of this audit lives in
> [`../lessons/LESSON_DEVELOPMENT_GUIDE.md`](../lessons/LESSON_DEVELOPMENT_GUIDE.md)
> §14 « LESSON REFERENCE ARCHITECTURE — FROZEN FOR GENERATION ». Read that, not
> this, to build a lesson. This file records what was checked, what was wrong,
> and what was changed.

## Scope

- **Lessons:** the 9 lessons of the 4AM unit « الأعداد الطبيعيّة والأعداد
  النّاطقة » (8 lessons + the synthesis `wadiya-idmajiya-aadad`), 40 modules,
  49 URLs (9 indexes + 40 modules).
- **Shared code:** `apps/web/src/lessons/common/` (kit, components, hooks,
  manipulations, knowledge, classroom, utils, queues), `packages/core`
  (parsers, practice evaluator, lesson access, stages), the API's evidence,
  progress, recommendation and practice judges.
- **Documentation:** the 17 lesson-related contracts and guides listed in
  `docs/README.md`, the components README, `packages/core/README.md`.
- **Method:** six read-only audits run in parallel (structure & routing,
  progress & mastery, mathematical correctness, diagnostics & knowledge,
  manipulations & shared components, documentation references), an e2e
  triage, and a runtime sweep of every URL at 1440 / 820 / 320 / 414 px
  (console, network, overflow, touch targets, unlabeled controls, Latin
  prose). Every finding below was verified in code before being acted on.

## Architecture map (derived from the code)

See the guide §14.1. In short: `App.jsx` → `buildLessonRoutes` →
`LessonClassroomShell` → per page `LessonAccessGate` + `KnowledgeProvider` →
`LessonIndex` or a module built on `ContentModule` / `PrerequisiteDiagnostic`
/ `BossFinal`, all inside `ModuleLayout`. Stages from `lessonStages.js`;
evidence only from the evaluation module, judged by the server registry.

## Documentation drift corrected

| Area | Documentation said | Code does | Status → action |
|---|---|---|---|
| Lesson duration | ≤ 45 min (LESSON_CONTRACT, core README) | `MAX_LESSON_MINUTES = 90` | DRIFT → 90 |
| Config typedef | `level: college/lycee`, 1-indexed `number`, `smaMetadata`, 3 styles | `moyen`, module 0, catalogue JSON, `diagnostic` style | OBSOLETE → rewritten |
| `passingScore` / `masteryThreshold` | used by boss / isMastered | read by nothing / non-sequential branch only | DRIFT → marked inert |
| Completion writes | module calls `markModuleCompleted` | `ModuleLayout` only, one rule | DRIFT → documented |
| Sequential unlock (integration guide §5) | `n <= 1`, mastery gate | `firstModuleNumber`, prerequisite bypass, no mastery gate | DRIFT → fixed |
| `onFinished` | « a step must never require it » | 4 steps wait on it (bounded, reachable) | AMBIGUITY → rule written |
| One selector | « only one on screen » | one per manipulation | DRIFT → clarified |
| Diagnostics | every `priorKnowledge` diagnosed by module 0, « always include module 0 » | 2 of 9 lessons; prior = earlier lessons too | DRIFT → optional, honest |
| Evidence retry | « retried on reconnection » | only when a final test mounted → now true | BUG → fixed + documented |
| Legacy evidence | transition window open | closed by default | BUG → fixed + documented |
| XP | « no XP system » (daily challenge) | client-only XP | DRIFT → fixed |
| Hydration | « before any lesson page opens » | asynchronous | DRIFT + BUG → both fixed |
| Math Lab | « nine instruments », « no lesson links to it » | 14 tools, `MathLabEntryButton` on every lesson page | DRIFT → fixed |
| Classroom entry | floating « ⛶ عرض » | « وضع القسم » in the marker row, lesson scope | DRIFT → fixed |
| Reference lessons | `vecteurs-2nde`, `fonctions-3e`, fractions 6e, French e2e suites | deleted 2026-09-25 | OBSOLETE → 4AM references |
| Pedagogy component tables | PartitionShape, Balance, FunctionMachine… | the 10 registry types | OBSOLETE → labelled historical |
| aria-labels | « French aria-labels » (playbook, pedagogy, integration guide) | Arabic everywhere | CONTRADICTION → Arabic |
| Copy vs reuse | « copy and adapt a lab » | closed registry, extend behind a prop | CONTRADICTION → reuse |
| Answer validation | `useAdaptiveExercise` pipeline | kit parsers / server judge | OBSOLETE → rewritten |
