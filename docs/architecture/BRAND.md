# Brand — the Smarter Academy logo

Authoritative for the logo, its files and where each one is used. Adopted by the
owner on **2026-10-21**; it replaced the star + figure + open-book emblem (and the
graduation-cap « S » baked into the old share image) everywhere.

## The mark

An **open ring holding a small isometric cube** — two fingers holding an idea to
try it: the platform's « learn with your hand, by experimenting ». No letter, no
literal drawing (owner: the earlier letter-« S » and illustrated proposals were
rejected).

- Ring: navy `#0B2A6F` → blue `#3B5BDB` gradient, open at the top-right.
- Cube: left face navy `#0B2A6F`, right face indigo `#4F46E5`, top face cyan
  `#22D3EE` → violet `#8B5CF6`.
- Wordmark: **Smarter** Manrope 800 ink `#0B1B3F`, **Academy** Manrope 500
  indigo `#4F5BD5`; in the SVG files the letters are outlines (no font needed).
- Mono variants: `white` (on dark / gradient) and `ink` (one colour: print,
  stamps); the cube's side faces keep 55 % / 80 % opacity so the volume reads.
- On a busy photograph, put the white logo on a calm area — its side faces are
  semi-transparent.

## Source and files

Everything is generated by **`scripts/brand/build-logo.py`** (geometry in code,
Manrope at `scripts/brand/fonts/`, OFL). Never edit a generated file by hand —
change the script and re-run it:

```bash
python3 scripts/brand/build-logo.py            # SVG + rasters (needs google-chrome)
python3 scripts/brand/build-logo.py --svg-only
```

| File (`apps/web/public/…`) | Use |
|---|---|

| `brand/mark-white.svg` | The dark `Footer` |
| `brand/logo-inline-color.svg` (and `-white`) | One line — the mark + « Smarter Academy » — for narrow headers: the EXPANDED `StudentNavbar` / `TeacherNavbar` sidebars (`h-9`, `px-5`: it fills the 256-px column); collapsed, they show the mark alone |
| `brand/logo-horizontal-color.svg` | Where no text follows the mark: `DiagnosticRun` header |
| `brand/logo-horizontal-{white,ink}.svg`, `brand/logo-stacked-{color,white}.svg`, `brand/mark-ink.svg` | Print, video, documents |
| `brand/logo-stacked-color.png` | JSON-LD `Organization.logo` in `index.html` |
| `brand/app-icon.svg` | Source of the home-screen icons |
| `favicon.ico` (16/32/48), `favicon-16x16.png`, `favicon-32x32.png` | Browser tab — the mark alone |

logo was replaced on 2026-10-21 (a one-off edit, not produced by the script). It
stays 256-colour and under 300 KB (`CLAUDE.md` « OG share cards »).

## Rules

- Use the files above; never redraw the mark locally or re-crop an old image.
- Next to visible « Smarter Academy » text, use the **mark alone** (square
  `width="200" height="200"`, `h-N w-N`); the full logo only where no name follows.
- The e-mail palette follows the logo (`brand.blade.php` header comment):
  navy `#0B2A6F`, indigo `#4F46E5`, cyan `#22D3EE`.
- Lesson content (`apps/web/src/lessons/`) never shows the logo.
